# Aula 11 - Testes unitarios e TDD

Material de apoio para a aula pratica de Qualidade de Software.

## Organizacao

- `projeto-aluno/`: projeto inicial a ser disponibilizado para os estudantes.

## Conteudos trabalhados

- testes unitarios com Python e pytest;
- estrutura Arrange, Act e Assert;
- cenarios validos, invalidos e de borda;
- excecoes esperadas com `pytest.raises`;
- ciclo Red, Green e Refactor;
- implementacao minima e refatoracao.
